## 🚀 Key Features

### 1. 🪐 3D WebGL Core Engine (`Three.js`)
- **Interactive Cyber Core**: Procedural 3D geometries, glowing wireframes, particle lattices, and dynamic camera transitions.
- **Dedicated 3D Project Worlds**: Unique thematic 3D environments rendered in real-time when inspecting each project (Security Lattice, Data Columns, Clock Torus, Decision Tree, Knowledge Sphere).
- **Custom Shaders**: GLSL vertex and fragment shaders for scanlines, glowing pulses, holographic dispersion, and matrix particle streams.

### 2. 💻 Integrated Cyber Terminal (`terminal.js`)
- Built-in interactive CLI terminal emulator supporting custom commands:
  - `whoami`, `about`, `skills`, `projects`, `experience`, `education`, `certifications`, `achievements`, `contact`
  - System controls: `matrix` (real-time falling green cipher rain overlay), `sound` (toggle synthesized FX), `reboot`, `clear`, `exit`.

### 3. 🔊 Pure Web Audio API Synthesizer (`audio.js`)
- Zero external audio files or mp3 dependencies.
- Native parametric oscillator sound design creating mechanical sci-fi clicks, ambient drones, terminal keystroke chirps, warp hums, and cybernetic alarms.

### 4. 🗂️ Rich Glassmorphism OS Architecture (`styles.css` & `app.js`)
- Modular HUD overlays, draggable windows, quick action dock, project drawer, and real-time system performance telemetry.
- Fully responsive across desktop, tablet, and mobile displays.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nikhil567890/nikhil_portofolio.git
   cd nikhil_portofolio
   ```

2. **Serve locally** (using any local static HTTP server):
   ```bash
   # Option A: Using Python 3
   python -m http.server 8080

   # Option B: Using Node.js npx serve
   npx serve .

   # Option C: Using VS Code Live Server extension
   # Right-click 'index.html' -> "Open with Live Server"
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8080` (or the port specified by your server).
